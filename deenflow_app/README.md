# DeenFlow — Daily Salafi Muslim Life Assistant

## 🌙 Vision
A modern, ultra-clean Islamic mobile/web assistant designed for the daily life guidance of a practicing Muslim. Strictly based on verified Islamic sources (Qur’an and Sahih Hadith) following the Athari methodology.

## 🚀 Workflows
1. **01_DeenFlow_Dashboard**: Serves a premium Web UI dashboard with prayer times, Ayah of the day, Sahih Hadith, and spiritual reminders.
2. **02_DeenFlow_AI_Assistant**: An AI Agent grounded in authentic sources to explain verses and hadith simply.
3. **03_DeenFlow_Tracker_Plan**: Automates spiritual tracking in Google Sheets and provides time-based reminders on Telegram.

## 📚 Core Data Sources
- **Qur’an**: Tanzil verified text via Quran Cloud/fawazahmed0 API.
- **Hadith**: Sahih Bukhari and Sahih Muslim via Sunnah.com/mhashim6 datasets.
- **Prayer Times**: Calculation logic based on `adhan-js`.

## 🛠️ Tech Stack
- **n8n**: Workflow automation engine.
- **OpenAI (GPT-4o)**: For the Iman Assistant.
- **Google Sheets**: Personal spiritual database.
- **Telegram**: Delivery channel for smart notifications.
- **HTML/CSS**: Minimalist dashboard UI.

## 🧭 UX Principles
- **Calm like Fajr.**
- **Clean like a mosque.**
- **Focused like prayer.**
- **No ads, no social mechanics, no innovations.**
